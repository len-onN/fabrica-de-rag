# Tests

Area compartilhada de testes e fixtures.

| Pasta | Uso |
| --- | --- |
| `contracts` | Exemplos JSON versionados para REST, worker, Qdrant, eventos, RAG, seguranca e MCP. |
| `e2e` | Playwright e fluxos ponta a ponta quando o Compose e as apps existirem. |
| `fixtures` | PDFs, JSONs e dados pequenos usados por unit, integration, smoke e e2e. |

Contratos ja existem porque os portoes documentais definiram a compatibilidade inicial. Fixtures executaveis entram nas branches das stacks e fluxos.
